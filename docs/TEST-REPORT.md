## 未完成的真實瀏覽器驗證（重要）

本容器的 Chromium 受系統企業政策 `URLBlocklist: ["*"]` 限制，Playwright 嘗試開啟 localhost、測試網址甚至 `data:` URL，均回報 **`net::ERR_BLOCKED_BY_ADMINISTRATOR`**。因此**不能聲稱已在真實 Chromium 以桌面或 390px 尺寸成功截圖／操作**。

仍需由使用者本機或允許開頁面的測試環境做以下驗收：

1. **桌面 1440×900／1366×768**：週網格 A/B 重疊顯示；單日焦點、半透明漸層、滾輪 32px 上限、4s／550ms／320ms 動畫與減少動態效果。
2. **手機 390×844**：標頭不換行溢出、日期插圖不卡邊、週網格可水平捲動、單日卡等寬且只上下捲動、底部工具不遮住重要操作。
3. **互動操作**：單擊預覽、雙擊編輯、長按 3 秒後拖移、時長把手、鎖定時無法拖移、表單新增／編輯／刪除／復原。
4. **資料交換**：新建行程後匯出 JSON、清空瀏覽器後再匯入、用品進度恢復、ICS 實際匯入 Apple 行事曆的時區顯示。
5. **地圖在線功能**：Leaflet 圖磚、真實位置、降級示意／Naver Maps 外連；部分地點仍需精確地址。
6. **變更鏈實測**：更換地點後確認相鄰路段刷新；費用頁只計當下相鄰且有價的路段；已鎖定行程保留。

**本回合結論**：可交付實際原始碼及可啟動的網站；純資料與 HTML 模板功能已跑過，但**不是完成全部桌面／手機 UI 的真機驗收**。不要把待測項目標為「通過」。
