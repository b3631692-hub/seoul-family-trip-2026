# 2026 首爾冬日暖心家族旅行｜可操作旅行手帖

以使用者提供的 **《2026 首爾五天四夜.docx》** 建立的繁體中文互動旅行規劃網站。日系淺色繪本風；**34 筆行程、5 個日期、10 人、31 件用品** 已匯入。採用原生 HTML / CSS / JavaScript ES Modules，**不需要安裝 npm 套件或申請 API 金鑰**。

## 立即啟動

**Windows**：解壓縮整個資料夾，雙擊 `start-windows.bat`。電腦需已安裝 Node.js 或 Python。

**macOS**：解壓縮後，在終端機進入資料夾，執行 `node server.mjs`（或 `python3 -m http.server 4173`）。也可以執行 `start-mac.command`（必要時先賦予執行權限）。

**所有系統**：在本專案目錄執行：

```bash
node server.mjs
# 或
python3 -m http.server 4173
```

然後在瀏覽器開啟 **http://localhost:4173**。

> 不要直接雙擊 `index.html` 以 `file://` 開啟：瀏覽器會阻擋透過 ES Module 讀取分離的 JSON 行程檔。部署到任何可提供靜態檔案的網頁伺服器，也可運行。

## 三個頁面

**行程規劃**：桌面左方地圖、交通摘要，右方週行事曆／單日時間軸；手機以單日時間軸優先垂直呈現。點選日期可切換 SVG 插圖；單擊卡片預覽、雙擊週行事曆卡片進入編輯，按住 **3 秒**才可拖移；週卡底部把手可調整時長。紅色當前時間只在「當地今天」且在時間範圍內時出現，每 15 秒更新。

**費用總覽**：韓元及新台幣分別統計；自行輸入 KRW→TWD 匯率後才產生跨幣別換算總額。每筆價格可設定 **每人／每車／全團**及數量、待估／已查證／情境狀態。所有未填金額為空值，**不會被當成免費**。

**攜帶用品**：六個分類，勾選進度、搜索、數量、備註、完成篩選，支援新增、編輯、刪除與復原。

畫面下方中央的綠色工具鈕向上展開，可新增行程、開啟旅程設定、復原、匯入／匯出 JSON、匯出 ICS、重設手冊初始資料。

## 編輯與備份

- 所有修改自動存至**目前瀏覽器的 localStorage**。無需登入、沒有雲端金鑰。**不同裝置不會自動同步**。
- 工具選單 → **匯出 JSON**，可獲取行程、地點、費用、手動交通、用品勾選、待查項目與匯率的完整副本。
- 工具選單 → **匯入 JSON**，可從另一台裝置或 AI 修改後的檔案恢復；替換前會確認，並可按復原。
- **匯出 ICS** 使用 `TZID=Asia/Seoul`、旅程當地年月日／時間和固定事件 ID，供 Apple 行事曆等支援 ICS 的行事曆匯入。**ICS 匯入是一批新行程，不代表與原有訂閱行事曆雙向同步；重複匯入可能產生重複事件。**
- 已確認／已預約的活動可以鎖定。鎖定狀態不可拖移或拉長；要更改時間必須先明確解除鎖定。
- 當資料檔更新但瀏覽器已存在本機草稿時，網站**優先保留本機草稿**。請先匯出備份，再**匯入更新後 JSON**；不會悄悄覆蓋你的確認結果。
- 尚未啟用多人共編雲端儲存。日後指定多人共編，應另外實作登入、手動同步、版本衝突與草稿保留；勿將金鑰寫入前端程式。

### 專案設計的關鍵原則

每筆活動含固定 `id`, `date`, `start`, `durationMinutes`, `category`, `title`, `address`, `cost`, `notes`, `locked`；群組 `group` 可為 `all`、`A`、`B`、`optional`。`routeOverrides` 使用 `fromId=>toId` 記錄人工設定。程式**只以當下相鄰的事件建立有效路段**：移動活動後，舊路段的人工備註仍保留，但只對當下相鄰的路段計費。跨 A/B 分組的平行行程不互判為衝突。日期列、旅行天數、日期圖示和地圖由 JSON 資料即時產生，並非固定五天的樣板。

原手冊未提供官方 CSS 或 SVG 原始附錄，故本版以使用者列出的色碼、DOM 命名、尺寸、動態時長及操作邏輯重建，**不是原版的像素級 1:1 複製**。

## 地圖與字型

有網路時，地圖優先使用 Leaflet + OpenStreetMap 圖磚；若外部資源無法使用，退化為**座標比例示意圖**與 Naver Map 外部連結。虛線是兩地**位置連線，不是經實際路由 API 驗證的行車／步行路徑**。有 GeoJSON 真實路線可在 `routeOverrides` 提供 `geometry` 陣列（`[[lng,lat], ...]`）。部分地址與經緯度尚不完整，不會假裝精確定位。

字體透過 Google Fonts 載入 Huninn（繁體中文粉圓字型）；離線時使用系統中文備援字體，不將字型檔重新打包。

## 查證與驗收

執行 `npm test` 跑 10 項純資料單元測試與桌面、390px 兩組 DOM 模板冒煙測試。完整測試範圍、瀏覽器驗證限制和待查問題見 `docs/TEST-REPORT.md`。

**最重要的行前確認**：江村鐵道自行車的 2.5 歲幼兒搭乘資格／2+4 人座混用；12/20 返程是包車還是機場巴士；實際航班／機場航廈；LEEJAE Hotel 詳細地址。已在「費用總覽」右欄標為優先檢查事項。
